# Caster 平台界面与结构（第一层）

2026-10-27 已观察生产环境单应用 CPU 镜像滚动升级页面；其他发布类型、终态、回滚路径仍须现场确认。本层只记录界面事实，动作顺序与验收归 [caster-release](../../scenarios/caster-release/SKILL.md)。

## 页面与对象

| 页面 / 区域 | 字段和控件语义 |
| --- | --- |
| Lightcone 实验列表关联入口 | CPU/GPU app 各有 Caster 链接、Moni监控、zone、镜像版本及实例数；入口不等于修改 Lightcone 配置 |
| Caster 应用详情 | 应用路径、环境、可用区；应用状态表展示资源池、配置资源、实例数、配置状态，以及迭代发布、容量发布、染色等控件 |
| 运行版本 | 发布版本号、基准标记、实际/目标实例数、Healthy、Discovery接流状态；版本号与镜像 tag 是不同标识 |
| 流程记录 | 类型、发起人、数据量筛选，审核工单、状态、创建时间等列 |
| 创建发布 | 顶部显示进行中的流程；表单展示应用名/ID、可用区、发布类型、是否生效新的应用配置、配置及实际实例数 |
| 发布预检 | 预检结果、应用信息、发起流程、取消 |
| 流程详情 / 审核 | 审核状态、申请人、理由、审核工单、确认发布、撤销流程；已观察“无需审核”分支 |
| 发布单 | 发布标识、init/deploying/paused、原地升级状态，详情、Diff信息、设置；旧/新版本健康/进行中/未知/错误计数、接流状态、阶段及倒计时 |
| 实例表 | 实例名、集群、IP、端口、镜像版本、状态、重启次数、健康状态、注册状态、启动时间；新/旧版本筛选与分页 |

## 发布表单

- 部署策略包含“滚动发布”；滚动策略包含“先起后停”“同起同停”。
- 镜像包含仓库、名称、版本 tag；异步加载后可显示当前 tag。
- “是否生效新的应用配置”控制是否附带应用配置更新。
- 并发度是数字，页面说明其同时代表最大可接受不在线实例数。另有自动暂停点、单批次超时、回滚免审批时间。
- “回滚执行方案”为文本框；本次填写“默认方案”，不是已证实存在同名下拉选项。
- 高级设置展示紧急发布、原地升级是否生效、配额校验、预估时间。预估不是完成承诺。
- 可出现单台、单台灰度、滚动阶段的 Webhook 字段；它们与聊天外发报告不是同一功能。

## 发布单与状态语义

- 详情展示目标镜像、替换版本、并发度、部署/滚动策略、超时等。Diff 信息展示旧/新应用配置；镜像 tag 由详情单独展示，不能假定一定在配置 diff 内。
- “继续”弹窗包含当前并发度、可选调整、“继续批次”“继续所有”；观察倒计时或正在部署时按钮可能禁用。
- 本案例阶段为 1 台 → 30% → 100%，并发度为 1；阶段目标数量不等于并发数。“继续批次”观察到只推进一个并发批次，并非一次完成整个阶段。
- 原地升级时，Pod 名称可以保留旧发布号；实例镜像已变化而名称不变，启动时间可更新，重启次数也可能仍为 0。
- 已观察 Updating/unhealthy/Unknown → Running/unhealthy/Unknown → Running/healthy/up。启动中的 unhealthy 可计入新版本错误数，计数本身不证明持续故障。
- paused 可表示批次/观察窗口暂停；不是失败终态。init、创建流程、确认发布也不证明实例已更新。
- 页面骨架先于数据到达，早期 0 实例、空列表和未生效字段可能是加载态。
